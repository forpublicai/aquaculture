# Inference Utility UI kit

Recreation of the "Home" frame from the Public AI Design System Figma file — the chat.publicai.co landing page ("Try Apertus"). Desktop breakpoint (1280px); the Figma file also defines tablet (834) and mobile (375) variants of the same sections.

Sections: Navigation → 140px "Try Apertus" display → chat box (interactive mock; the Figma frame embeds a live code instance here) → infrastructure tagline → feature card grid → About/Contributing rows → partner logo cloud → centered CTA → footer.

Copy in the Figma frame is partly placeholder ("Call out a feature…", "Some subtitle") — kept where real copy exists, lightly substituted where the frame itself is placeholder.
